# The Healthy Habit — Premium Landing Page

A lightweight, mobile-first static website for The Healthy Habit, Nakhara, Bhubaneswar.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in Chrome/Edge/Firefox.
3. For live reload, open the folder in VS Code and use the Live Server extension.

## Publish free
Upload the contents to a GitHub repository and enable GitHub Pages, or deploy the folder to Cloudflare Pages.

## Edit
- `index.html` — text, products, prices, links
- `styles.css` — design and responsive layout
- `script.js` — WhatsApp order behaviour and animations
- `assets/` — supplied menu/subscription banners

## WhatsApp
The site uses WhatsApp number `8598824098`. Change the `WA` value in `script.js` if the ordering number changes.

## Google Maps
The directions buttons use the shop's exact Google Maps link provided for this site.


Latest cosmetic update: menu/category icons use lightweight inline SVG illustrations with a soft 3D card treatment; no external icon library is required.
